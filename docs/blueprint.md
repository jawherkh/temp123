# **App Name**: SunWise

## Core Features:

- Smart Diagnostic Questionnaire: A questionnaire to gather user's skin profile (phototype, concerns, preferences).
- AI-Powered Recommendation Engine: Generative AI tool to provide tailored dermocosmetic recommendations, focusing on sunscreens, based on questionnaire results.
- Personalized Product Display: Display personalized sunscreen recommendations with product details and where to purchase.
- Educational Content: Educational resources with videos and reminders on sun protection.
- Multilingual Support: Multilingual support for French and Arabic.

## Style Guidelines:

- Primary color: Soft blue (#B0E2FF) to convey trust and healthcare.
- Secondary color: Light green (#90EE90) for a natural, healthy feel.
- Accent: Coral (#FF7F50) for calls to action and highlighting key information.
- Clean, card-based layout for product recommendations and educational content.
- Use simple, clear icons to represent skin types, concerns, and product features.
- Subtle transitions and animations for a smooth, engaging user experience.

## Original User Request:
Develop an AI-powered mobile and web application called DermIA that assists users in making personalized, evidence-based dermocosmetic product choices, especially sunscreens, based on a smart diagnostic questionnaire (and later, facial scan). The app should generate tailored recommendations using skin profile data (phototype, concerns, preferences) and provide a dedicated pharmacist interface to view user profiles, adjust suggestions, and offer printable advice. Include features like educational content (videos, reminders), multilingual support (French/Arabic), data privacy compliance (RGPD), and an admin panel to manage product data. The app targets pharmacy clients, pharmacists, and caregivers, with the goal of improving skin treatment adherence and pharmacist-patient engagement.
